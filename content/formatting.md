### `📝 My File Format Guide`
*Use this note as a quick reference for the standard format of all notes in this vault.*

---

## Core Structure

1.  **Start with H2:** Every note begins with a level 2 heading (`##`). The title of the note is the H2.
2.  **Subheadings are H3:** Any sections within the note use a level 3 heading (`###`). Use H4 (`####`) sparingly if you need to nest further.
3.  **Private/Draft Files:** If a note is not ready or is private, add this YAML frontmatter at the very top of the file:

   ```yaml
	---
	draft: true
	---
   ```

---

## Text Formatting & Grammar

*   **Bold Emphasis:** Use `**bold**` to emphasize key terms.
    *   **Rule:** Do **not** include trailing punctuation inside the bold syntax.
    *   *Correct:* This is **important**.
    *   *Incorrect:* This is **important.**

*   **Line Breaks:** End a sentence with **two spaces** before hitting `Enter` to create a clean line break. This improves readability in edit mode.
    *   *Example:* `This is the end of a sentence.  ` -> *Enter*
        `This is a new line.`

*   **Lists:** Use `-` for bullet points. Indent with two spaces for nested lists.

---

## Quick-Checks Before Saving

*   [ ] Note starts with `## [Title]`.
*   [ ] Subheadings are `###`.
*   [ ] Draft notes have `draft: true` in the frontmatter.
*   [ ] **Bold** text does not include punctuation (`**word**`, not `**word.**`).
*   [ ] Sentences end with double spaces for line breaks.
